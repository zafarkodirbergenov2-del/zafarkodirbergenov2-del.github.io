Privacy Policy

Jarvis · last updated 26 November 2026

Jarvis is a private application with a single user: the person who installed it and who owns the Google Account it connects to. This policy describes how it handles that person's data.

Who runs it

Jarvis runs entirely on the owner's own computer. There is no shared server, no hosted backend that other people use, and no other users.

What data is accessed

  • Google Calendar — events on the owner's own calendar, in order to display them and to create, move or delete events the owner asks for.
  • Gmail — messages in the owner's own mailbox, in order to display them and to draft or send replies the owner asks for.

How the data is used

Data is read only to answer the owner's own requests, and is shown only to the owner, in their own private Telegram chat. It is never used for advertising, profiling, training machine-learning models, or any purpose unrelated to the owner's requests.

Sharing

Data is not sold, rented, or shared with third parties. Requests are processed by Anthropic's Claude API, which the application uses to understand and answer them; no Google user data is shared with anyone else.

Storage

Access tokens are stored on the owner's own computer. Notes the owner asks Jarvis to remember are stored in a private database that only the owner controls. No copy of the owner's calendar or mailbox is kept.

Retention and deletion

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Deleting the stored token file on the computer removes the application's access immediately, and deleting the application removes all stored data.

Limited Use

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to the developer at the support address shown on the application's Google consent screen.
